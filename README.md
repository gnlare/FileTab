# FileTab (C++ / Win32)

WPF(.NET) 버전 FileTab 을 **외부 라이브러리 없이 순수 Win32 C++20** 으로 다시 만든 버전입니다.
실행 파일 하나(`FileTab.exe`, 정적 CRT)로 동작하며 .NET 런타임이 필요 없습니다.

> **먼저 읽어 주세요 — 검증 범위**
> 이 코드는 Windows 가 없는 환경에서 작성했습니다.
> - 플랫폼 독립 코어(`src/core`, 경로 규칙·이력·정렬·JSON·설정·캐시)는 Linux g++ 로 빌드해 **92개 검사를 통과**했습니다.
> - Windows 코드(`src/win`)는 **실제 Windows SDK 로 컴파일하거나 실행해 보지 못했습니다.** 가짜 헤더로 구문·선언 오류만 점검했습니다.
>   그래서 첫 빌드에서 SDK 시그니처 차이로 컴파일 오류가 나거나, 첫 실행에서 동작 차이가 있을 수 있습니다. 오류 메시지를 알려 주시면 바로 고치겠습니다.

## 빌드

요구 사항: Visual Studio 2022 이상(C++ 데스크톱 개발 워크로드) 또는 CMake 3.20+ 와 MSVC.

```bat
build.bat
```

또는 Visual Studio 에서 **폴더 열기**로 이 폴더를 열면 CMake 프로젝트로 인식합니다.
결과물: `build\Release\FileTab.exe`. 코어 테스트: `build\Release\core_tests.exe` (또는 `ctest`).

설정 파일은 기존 WPF 버전과 같은 `%LOCALAPPDATA%\FileTab\settings.json` 이고 **형식도 같습니다**(북마크, 폴더 그룹, 탭, 창 크기 그대로 이어서 사용). 환경 변수 `FILETAB_SETTINGS_DIR` 로 위치를 바꿀 수 있습니다.

## 속도 개선 (WPF 버전 대비)

| 영역 | WPF 버전 | 이 버전 |
|---|---|---|
| 폴더 읽기 | `EnumerateFileSystemInfos` + 항목 객체 생성 | `FindFirstFileEx`(기본 정보, 큰 버퍼)로 크기·시각·속성을 한 번에. 정렬까지 워커 스레드에서 끝내고 UI 는 교체만 |
| 일반 아이콘 | 파일마다 `SHCreateItemFromParsingName` + `GetImage` | **확장자별로 한 번만** 시스템 이미지 목록에서 만들어 공유(디스크 접근 없음, 첫 화면에서 즉시 표시) |
| 개별 아이콘/썸네일 | 모든 파일 | exe·lnk·ico 등 파일마다 아이콘이 다른 형식, **썸네일 처리기가 등록된 형식**, 사용자 지정 폴더 아이콘만 비동기로. 도착 전에는 일반 아이콘을 보여 주므로 빈 칸이 없음 |
| 스크롤 중 작업 | 요청이 쌓임 | 화면에서 사라진 항목의 대기 요청은 버림(보이는 항목 우선) |
| 이미지 캐시 | 경로 문자열 키 | 64비트 해시 키(경로·수정 시각·크기·크기 단위), 96MB LRU. 폴더 내용이 바뀌어도 폴더 아이콘은 다시 만들지 않음 |
| 새로 고침 | 컨테이너를 병합 | 목록이 완전히 같으면 **아무것도 바꾸지 않음**. 다르면 선택·초점·스크롤 위치를 이름 기준으로 복원 |
| 탭 전환 | 매번 다시 읽고 화면 갱신 | 탭별 목록·선택·스크롤을 보관해 즉시 표시, 뒤에서 조용히 확인만 함 |
| 목록 그리기 | WPF 컨테이너/템플릿 | 보이는 행만 직접 그리는 가상 목록(더블 버퍼). 항목 수와 무관 |
| 이름 폭 계산 | `FormattedText` | GDI 텍스트 측정(보이는 항목만) |
| 파일 변경 감시 | `FileSystemWatcher` | `ReadDirectoryChangesW` + 200ms 묶음 + 450ms 디바운스, 읽는 중이면 대기 |

## 기능 (WPF 버전과 동일하게 구현)

- 단일 / 좌우 분할(F6), 분할선 드래그, 활성 패널 표시
- 패널별 탭: 새 탭(`Ctrl+T`), 닫기(`Ctrl+W`, 우클릭, 휠 클릭), `Ctrl+Tab` 전환, **끌어서 순서 변경**, 마지막 탭을 닫으면 홈 탭 생성
- 뒤로/앞으로/위로(`Alt+←/→/↑`, 마우스 뒤로/앞으로 버튼, `Backspace`), 이동 경로(브레드크럼, 길면 `…` 로 접힘), 주소 직접 입력(`Ctrl+L`, `.lnk` 입력 시 대상 폴더로 이동)
- 보기: 자세히 / 큰 아이콘(128px) / 보통 아이콘(64px), 설정에서 아이콘 여백 조정
- 자세히: 이름·크기·수정한 날짜 열 클릭 정렬(폴더 우선, 자연 정렬), 열 너비 조절
- 다중 선택(`Ctrl`/`Shift` 클릭, `Ctrl+A`, 방향키·Home/End/PageUp/PageDown), 글자 입력으로 항목 찾기
- 복사/붙여넣기(Windows 파일 클립보드), 삭제(휴지통)·`Shift+Delete`(영구), 이름 바꾸기(`F2`), 새 폴더(하위 폴더 한 번에), 열기(`Enter`·더블 클릭, 바로 가기·링크 폴더 처리)
- 파일 작업은 Windows `IFileOperation` 으로 수행(진행률·충돌 대화상자·실행 취소 기록)
- 북마크 줄: 클릭 이동, 우클릭 수정/삭제, ★ 로 현재 폴더 추가, **탐색기에서 폴더 끌어다 놓기**, 파일 목록에서 드래그해 내보내기
- 폴더 그룹(📁): 추가·수정·삭제·불러오기
- 창 크기·최대화·분할 비율·탭 상태 저장/복원, PerMonitorV2 DPI, 긴 경로 지원 매니페스트

## 원본과 다른 점

- 자세히 보기의 **열 순서 바꾸기**는 구현하지 않았습니다(열 너비 조절과 정렬은 있음).
- 아이콘 보기에서 마우스 휠은 한 번에 아이콘 한 줄씩 스크롤합니다(WPF 버전은 세 줄).
- 상태 줄에는 선택이 없을 때 항목 수 또는 오류(`열기 실패: …`)를 보여 줍니다.
- 목록 우클릭 메뉴는 선택 상태에 따라 항목을 회색으로 표시합니다.
- 이름 바꾸기·새 폴더에서 잘못된 이름은 대화상자 안에서 바로 알려 줍니다.

## 구조

```
src/core   플랫폼 독립(테스트 가능): 경로 규칙, 이력, 항목 모델/정렬, JSON, 설정, LRU 캐시
src/win    Win32: 폴더 읽기/감시, Shell 파일 작업, 이미지 서비스, 탭 모델, 목록 컨트롤(FileView),
           패널(PaneView), 대화상자, 메인 창
tests      코어 테스트(WPF 버전의 FileTab.Core.Tests 항목 + 정렬·JSON·설정·캐시)
resources  아이콘, 매니페스트(PerMonitorV2·긴 경로), .rc
```
