# FileTab (C++ / Win32)

**FileTab**은 가볍고 빠른 성능을 목표로 개발된 Windows용 탭 기반 듀얼 패널 파일 관리자입니다.  
기존 .NET(WPF) 버전의 편의성을 계승하면서, 외부 런타임 의존성 없이 **순수 Win32 C++20 단일 실행 파일(`FileTab.exe`)**로 재설계되어 즉각적인 반응성과 낮은 리소스 사용량을 제공합니다.

---

## 주요 기능

### 1. 탭(Tab) 기반 폴더 관리
- **다중 탭 지원**: 한 패널 내에서 여러 폴더를 탭으로 띄워 빠르게 전환할 수 있습니다. (`Ctrl+T`, `Ctrl+W`, 마우스 휠 클릭, 우클릭 닫기)
- **유동적 탭 너비 & 말줄임**: 탭 제목은 폴더명 길이에 따라 유동적으로 결정되며, 최대 너비(100px)를 초과할 경우 말줄임표(`...`)로 깔끔하게 축약됩니다.
- **열린 탭 목록 메뉴**: 탭 수가 많아 창 너비를 넘어가는 경우 탭 추가(+) 버튼 왼쪽에 목록(▼) 버튼이 자동으로 생성되어 원하는 탭으로 즉시 이동할 수 있습니다.
- **탭 색상 커스텀 지정**: 탭 우클릭 메뉴를 통해 6가지 대표 컬러 또는 사용자 지정 색상(Windows 색상 선택기)을 부여하여 프로젝트/작업별로 탭을 시각적으로 구분할 수 있습니다.
- **드래그 앤 드롭 순서 변경**: 탭을 마우스로 끌어서 원하는 위치로 직관적으로 재배치할 수 있습니다.

### 2. 단일 / 좌우 분할 패널 (Dual Pane)
- **듀얼 패널 전환**: `F6` 단축키 또는 상단 버튼 클릭으로 언제든지 단일 창과 좌우 분할 패널 모드를 전환할 수 있습니다.
- **자유로운 분할 비율 조절**: 중앙 분할선을 마우스 드래그하여 패널 너비 비율을 자유롭게 설정할 수 있습니다.
- **손쉬운 파일 작업**: 두 패널 간 드래그 앤 드롭이나 단축키 복사/이동을 지원하여 파일 정리가 한결 편리합니다.

### 3. 다양한 보기 모드 & 비주얼 설정
- **3가지 보기 모드**:
  - **자세히(Details)**: 이름, 크기, 수정한 날짜 열 표시, 컬럼 헤더 클릭 정렬(폴더 우선/자연 정렬), 컬럼 너비 조절
  - **큰 아이콘(128px)** / **보통 아이콘(64px)**: 그리드 형태의 타일 뷰
- **아이콘 여백 조절**: 설정 창의 비주얼 카테고리에서 보기 모드별 상하 x 좌우 여백(px)을 세밀하게 커스터마이징할 수 있습니다.
- **다크 모드(Dark Mode) 지원**: 눈의 피로를 덜어주는 완성도 높은 다크 테마를 기본 제공하며, 시스템/사용자 설정에 맞춰 타이틀바, 메뉴, 대화상자, 텍스트 및 버튼까지 일관된 테마를 적용합니다.
- **미니멀 오버레이 스크롤바**: 회색 배경 거터 없이 콘텐츠 위에 슬림하게 얹히는 반투명 오버레이 스크롤바를 적용하여 넓고 쾌적한 화면을 제공합니다.

### 4. 강력한 주소 탐색 & 브레드크럼
- **경로 표시줄(Breadcrumb)**: 상위 폴더 단계가 개별 버튼으로 나열되어 원하는 상위 경로를 한 번의 클릭으로 즉시 이동할 수 있습니다.
- **주소창 직접 편집 (`Ctrl+L`)**: 주소를 직접 입력하여 이동할 수 있으며, 입력한 경로가 바로 가기(`.lnk`)인 경우 원본 대상 폴더를 자동으로 추적하여 열어줍니다.
- **이력 탐색**: 브라우저와 동일하게 뒤로/앞으로/상위 폴더(`Alt+←`, `Alt+→`, `Alt+↑`, `Backspace`, 마우스 앞/뒤 버튼) 이동을 완벽하게 지원합니다.

### 5. 북마크 및 폴더 그룹 (Folder Groups)
- **북마크 바**: 자주 사용하는 폴더를 북마크에 등록하여 원클릭으로 이동할 수 있습니다.
  - 별(★) 버튼으로 현재 경로 즉시 추가
  - Windows 탐색기나 파일 목록에서 폴더를 북마크 바로 직접 끌어다 놓기(Drag & Drop)
  - 북마크 우클릭 메뉴로 이름 및 경로 편집 / 삭제
- **폴더 그룹(📁)**:
  - 현재 열려 있는 탭들의 경로, 보기 모드, 탭 색상 설정을 통째로 하나의 그룹으로 저장
  - 저장된 그룹을 클릭하면 해당 탭 구성이 그대로 복원
  - 그룹 메뉴에서 우클릭 시 그룹 수정 / 삭제 대화상자 지원

### 6. 단축키 사용자 정의
- 설정 창의 **단축키 (키보드)** 섹션에서 주요 기능의 단축키를 목록으로 확인하고 원하는 키 조합으로 손쉽게 변경하거나 기본값으로 초기화할 수 있습니다.
- 설정 창의 모든 값은 하단의 **확인**을 눌러야 최종 반영되며, 취소 시 기존 설정이 온전히 유지됩니다.

### 7. Windows 네이티브 기능 연동 및 고성능 구조
- **비동기 폴더 탐색**: 작업자 스레드 풀을 통해 파일 목록을 비동기로 로드하여 폴더 내용이 방대해도 UI 프리징이 발생하지 않습니다.
- **지능형 아이콘 & 썸네일 캐시**: 공통 확장자 아이콘을 공유 캐싱하고, 이미지/실행 파일 썸네일은 화면에 표시되는 항목 위주로 비동기 로드(LRU 캐시)하여 쾌적한 스크롤을 보장합니다.
- **실시간 파일 시스템 감시**: `ReadDirectoryChangesW` 기반으로 외부에서 파일이 생성/수정/삭제되어도 목록에 즉시 반영됩니다.
- **안전한 파일 작업 (`IFileOperation`)**: 복사, 이동, 삭제(휴지통 지원), 영구 삭제(`Shift+Delete`), 이름 바꾸기(`F2`), 새 폴더 생성 시 Windows 표준 셸 엔진을 사용하여 진행 대화상자, 충돌 처리 및 실행 취소(`Ctrl+Z`)를 안전하게 지원합니다.
- **표준 클립보드 & OLE 드래그 앤 드롭**: 외부 응용 프로그램 및 Windows 탐색기와 원활하게 파일을 주고받을 수 있습니다.

## 기본 단축키 안내

설정 창의 "단축키" 탭에서 자유롭게 변경할 수 있습니다.

| 기능 | 기본 단축키 | 설명 |
|---|---|---|
| **좌우 분할 / 단일 창 전환** | `F6` | 단일 패널과 듀얼 패널 모드를 토글합니다. |
| **새 탭** | `Ctrl+T` | 현재 폴더를 새 탭으로 복제하여 엽니다. |
| **탭 닫기** | `Ctrl+W` | 활성화된 탭을 닫습니다. (마우스 휠 클릭도 가능) |
| **주소창 입력** | `Ctrl+L` | 경로 표시줄을 주소 입력창으로 전환합니다. |
| **상위 폴더 이동** | `Alt+Up`, `Backspace` | 한 단계 상위 디렉터리로 이동합니다. |
| **뒤로 이동** | `Alt+Left` | 이전 방문 경로로 이동합니다. (마우스 뒤로 가기 버튼 지원) |
| **앞으로 이동** | `Alt+Right` | 다음 방문 경로로 이동합니다. (마우스 앞으로 가기 버튼 지원) |
| **현재 폴더 북마크** | `Ctrl+D` | 현재 위치를 북마크 바에 추가합니다. |
| **탭 간 순환 이동** | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 열려 있는 탭들을 순서대로 전환합니다. |
| **새로 고침** | `F5` | 현재 폴더의 파일 목록을 다시 읽습니다. |
| **이름 바꾸기** | `F2` | 선택된 항목의 이름을 변경합니다. |
| **삭제** | `Delete` | 선택된 항목을 휴지통으로 이동합니다. |
| **영구 삭제** | `Shift+Delete` | 휴지통을 거치지 않고 영구 삭제합니다. |
| **클립보드 복사 / 잘라내기 / 붙여넣기** | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 파일 클립보드 작업을 수행합니다. |
| **전체 선택** | `Ctrl+A` | 현재 폴더의 모든 항목을 선택합니다. |

## 빌드 방법

### 요구 사항
- Windows 10 / 11
- Visual Studio 2022 이상 ("C++를 사용한 데스크톱 개발" 워크로드 포함) 또는 CMake 3.20+ 및 MSVC

### 빌드 스크립트 실행
저장소 루트에서 `build.bat`을 실행하면 자동으로 Release 빌드가 진행됩니다:

```bat
build.bat
```

빌드가 완료되면 `build\Release\FileTab.exe` 실행 파일과 `build\Release\core_tests.exe` 단위 테스트 실행 파일이 생성됩니다.

### Visual Studio에서 열기
Visual Studio에서 **파일 > 열기 > 폴더**로 이 저장소 디렉터리를 열면 CMake 프로젝트로 자동 인식되며, Visual Studio 내에서 바로 빌드 및 디버깅(`F5`)이 가능합니다.

## 설정 파일 안내

설정 데이터(북마크, 폴더 그룹, 탭 복원 상태, 아이콘 여백, 단축키, 창 크기 및 테마 등)는 JSON 형식으로 저장됩니다.

- **기본 저장 경로**: `%LOCALAPPDATA%\FileTab\settings.json`
- **커스텀 경로 지정**: 환경 변수 `FILETAB_SETTINGS_DIR`을 설정하여 저장 위치를 원하는 폴더로 변경할 수 있습니다.
- 기존 .NET 버전 FileTab의 `settings.json`과 데이터 호환이 가능합니다.

## 프로젝트 디렉터리 구조

```
FileTab-cpp/
├── src/
│   ├── core/         # 플랫폼 독립 코어 모듈 (경로 유틸, 정렬 알고리즘, JSON 파서, 설정 모델, LRU 캐시)
│   └── win/          # Win32 GUI 및 Windows 셸 연동 (MainWindow, PaneView, FileView, Dialogs, 이미지 서비스 등)
├── tests/            # 코어 로직 단위 테스트 코드
├── resources/        # 애플리케이션 아이콘, 리소스 스크립트, DPI/긴 경로 매니페스트
├── build.bat         # 자동 빌드 스크립트
└── CMakeLists.txt    # CMake 빌드 정의 파일
```
