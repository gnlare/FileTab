# FileTab

**FileTab**은 가볍고 빠른 Windows용 탭 기반 듀얼 패널 파일 관리자입니다.  
순수 C++20 / Win32 API로 개발되어 별도의 런타임 없이 단일 실행 파일(`FileTab.exe`)로 동작합니다.

---

## 주요 기능

- **탭 폴더 관리**: 다중 탭, 탭 색상 지정, 탭 순서 드래그 변경, 탭 목록(▼) 메뉴
- **듀얼 패널 (`F6`)**: 단일 창 및 좌우 분할 패널 전환, 패널 간 드래그 앤 드롭 파일 복사/이동
- **강력한 검색 (`Ctrl+F`)**: 와일드카드(`*.txt`, `*.*`) 지원, 하위 폴더 검색, 텍스트 파일 내 포함 문자 검색, 키 입력 빠른 찾기
- **북마크 및 폴더 그룹**: 자주 쓰는 경로 북마크 및 열려 있는 탭 구성을 그룹(📁)으로 일괄 저장/복원
- **커스텀 비주얼**: 다크 모드 지원, 미니멀 오버레이 스크롤바, 보기 모드별(자세히/큰 아이콘/보통 아이콘) 여백 조절
- **단축키 설정**: 설정 창에서 주요 기능의 단축키를 사용자가 원하는 키 조합으로 변경 가능
- **외부 연동**: 탐색기 및 다른 윈도우 앱과의 표준 OLE 드래그 앤 드롭 상호작용 지원

## 기본 단축키

| 기능 | 기본 단축키 |
|---|---|
| **좌우 분할 / 단일 창 전환** | `F6` |
| **찾기 (검색창 포커스)** | `Ctrl+F` |
| **주소창 입력** | `F4` |
| **새 탭 / 탭 닫기** | `Ctrl+T` / `Ctrl+W` |
| **상위 폴더 이동** | `Alt+Up`, `Backspace` |
| **뒤로 / 앞으로 이동** | `Alt+Left`, `Alt+Right` |
| **현재 폴더 북마크** | `Ctrl+D` |
| **이름 바꾸기 / 삭제** | `F2` / `Delete` (`Shift+Delete` 영구 삭제) |
| **새로 고침** | `F5` |

> 단축키는 상단 **설정 > 키보드** 메뉴에서 자유롭게 변경할 수 있습니다.

## 빌드 방법

- **요구 사항**: Windows 10/11, Visual Studio 2022 이상 ("C++를 사용한 데스크톱 개발" 워크로드) 또는 CMake 3.20+
- 저장소 루트에서 `build.bat`을 실행하면 `build\Release\FileTab.exe`가 생성됩니다.

```bat
build.bat
```

---

## 설정 저장 위치

- `%LOCALAPPDATA%\FileTab\settings.json`
- 환경 변수 `FILETAB_SETTINGS_DIR`을 통해 저장 디렉터리를 변경할 수 있습니다.
